# 쑥쑥 놀이터 🌱

만 4~5세 유아를 위한 **누리과정 연계 인터랙티브 애니메이션 놀이 학습 Android 앱**입니다.
새싹 친구 **쑥쑥이**와 함께 10가지 놀이를 하며 누리과정 5개 영역(신체운동·건강, 의사소통, 사회관계, 예술경험, 자연탐구)을 고르게 경험합니다.

- Kotlin + Jetpack Compose, 단일 액티비티
- 모든 그림·캐릭터·애니메이션은 코드(Compose Canvas)로 그리고, 효과음과 실로폰 소리도 코드로 합성합니다. 외부 이미지·음원 파일이 없습니다.
- 모든 안내를 한국어 음성(TTS)으로 들려주어 글을 읽지 못해도 혼자 놀 수 있습니다.
- 인터넷 권한 없음, 광고·결제·외부 전송 없음. 기록은 기기 안에만 저장됩니다.

## 놀이 구성과 누리과정 연계

| 놀이 | 누리과정 영역 | 관련 내용 | 만 4세 | 만 5세 |
|---|---|---|---|---|
| 가 **한글 놀이** – 자음 카드 보며 따라 쓰기 / 첫소리가 같은 그림 찾기 | 의사소통 | 주변의 상징, 글자 등의 읽기에 관심을 가진다 · 말과 글의 관계에 관심을 가진다 | 선택지 3개 | 모양이 비슷한 자음(ㄱ/ㅋ, ㄷ/ㅌ …)을 오답으로 섞음 |
| 🍎 **숫자 세기** – 하나씩 눌러 세고 알맞은 숫자 고르기 | 자연탐구 | 물체를 세어 수량을 알아본다 | 1~5 | 1~10 (다섯 칸씩 두 줄) |
| 🎈 **색깔 풍선** – 말하는 색의 풍선만 터뜨리기 | 예술경험 | 예술적 요소(색)에 관심을 가지고 찾아본다 | 4가지 색 | 7가지 색, 더 빠르게 |
| 🔺 **모양 맞추기** – 도형 조각을 끌어 같은 모양 자리에 넣기 | 자연탐구 (+신체: 소근육) | 물체의 위치와 방향, 모양을 알고 구별한다 | 3개 × 2판 | 5개 × 3판 |
| 🃏 **짝꿍 카드** – 같은 그림 두 장 찾기 | 자연탐구 | 탐구과정 즐기기(기억하고 비교하기) | 4쌍, 3초 미리 보기 | 6쌍, 2초 미리 보기 |
| 🐞 **규칙 찾기** – 반복 규칙 다음에 올 그림 고르기 | 자연탐구 | 주변에서 반복되는 규칙을 찾는다 | AB, AAB | AB, AAB, ABB, ABC |
| 😊 **기분 친구** – 상황 이야기를 듣고 친구의 기분 표정 고르기 | 사회관계 | 나의 감정을 알고 상황에 맞게 표현한다 · 서로 다른 감정을 존중한다 | 기쁨·슬픔·화남·놀람 | + 무서움 |
| 🖍️ **그림 그리기** – 크레용·무지개 붓·도장·지우개 | 예술경험 | 다양한 미술 재료와 도구로 생각과 느낌을 표현한다 | 자유 | 자유 |
| 🎵 **실로폰** – 자유 연주 / 반짝이는 막대 따라 노래 치기 | 예술경험 | 신체, 사물, 악기로 간단한 소리와 리듬을 만들어 본다 | 노래 앞부분 | 노래 전체 |
| 🤸 **쑥쑥 체조** – 쑥쑥이 동작 따라 하기(만세·박수·뛰기·균형·숨쉬기) | 신체운동·건강 | 신체 움직임을 조절한다 · 기본 운동 능력을 발휘한다 | 5동작 | 7동작 |

> 영역·내용 범주는 2019 개정 누리과정(교육부·보건복지부 고시)을 기준으로 정리했습니다. 수업·연구에 활용하실 때는 고시 원문과 해설서를 함께 확인해 주세요.

실로폰 노래는 저작권이 만료된 전래 선율(도레미 계단, 반짝반짝 작은 별, 비행기)만 사용하고 가사는 넣지 않았습니다.

## 설계 원칙

유아의 발달 특성과 놀이 중심 교육과정의 취지를 반영했습니다.

1. **글을 몰라도 혼자 놀 수 있게** – 모든 지시와 피드백을 음성으로 들려주고, 그림 중심으로 구성했습니다. 🔊 버튼으로 언제든 다시 들을 수 있습니다.
2. **실패 부담 없는 피드백** – 틀려도 "다시 해 볼까요?"처럼 격려하고, 틀린 선택지만 흐리게 하여 스스로 다시 찾도록 합니다. 오답일 때도 배울 거리를 알려 줍니다(예: "나비는 니은으로 시작해요", "이건 파란색 풍선이에요").
3. **점수 대신 참여 칭찬** – 아이 화면에는 점수·등급이 없습니다. 놀이를 끝까지 하면 스티커를 받고, 첫 시도 정답률은 보호자 화면에서만 보여 줍니다.
4. **감정의 다양성 존중** – 기분 친구 놀이에서 다른 감정을 고르면 "그렇게 느낄 수도 있어요"라고 받아 주고, 정답 뒤에는 감정을 말로 표현하고 조절하는 방법(숨 크게 쉬기, 어른에게 도움 요청하기)을 들려줍니다.
5. **짧은 활동 단위** – 한 번의 놀이는 3~5분 안팎(5문제 내외)으로 구성했습니다.
6. **연령별 난이도** – 만 4세는 범위를 좁혀 성공 경험을 먼저 쌓고, 만 5세는 범위를 넓히고 헷갈리기 쉬운 선택지를 섞습니다.
7. **바른 미디어 사용 습관** – 보호자가 정한 시간(기본 20분)이 지나면 놀이를 끊지 않고, 놀이를 마친 뒤 "쉬는 시간" 화면을 보여 줍니다. 보호자 확인 후에만 이어서 놀 수 있습니다. 쑥쑥 체조로 화면 시간 사이에 몸을 움직이게 합니다.
8. **안전과 개인정보** – 위험 권한과 인터넷 권한이 없고, 보호자 메뉴는 두 자리 덧셈 문제로 잠겨 있습니다.

## 화면 구성

- **첫 실행**: 쑥쑥이가 인사하고 나이(만 4세/5세)를 물어봅니다.
- **홈**: 움직이는 하늘·구름·언덕 배경 위에 10가지 놀이 타일, 받은 별 수, 스티커 책, 보호자 메뉴 버튼
- **놀이 화면**: 집 버튼, 진행 별, 다시 듣기 버튼 / 놀이를 마치면 색종이 축하와 새 스티커
- **스티커 책**: 모은 스티커 30종(눌러서 이름 듣기)
- **보호자·교사 메뉴**(두 자리 덧셈으로 확인)
  - 오늘/누적 놀이 시간, 완료한 놀이 수, 스티커 수
  - 누리과정 영역별 놀이 횟수 막대그래프
  - 놀이별 횟수·첫 시도 정답률·관련 누리과정 내용
  - 설정: 아이 나이, 음성 안내, 효과음, 쉬는 시간 알림(끄기/10/15/20/30분), 기록 초기화

## 설치하기

### 방법 1. 빌드된 APK 받기 (GitHub Actions)

이 저장소의 GitHub Actions가 `kids-edu-app/` 변경 때마다 테스트 → Lint → 디버그 APK 빌드를 실행합니다.

1. 저장소의 **Actions** 탭 → **쑥쑥 놀이터 Android 빌드** → 최근 성공한 실행을 엽니다.
2. 아래 **Artifacts**에서 `ssukssuk-playground-debug-apk`를 내려받아 압축을 풉니다.
3. `app-debug.apk`를 Android 기기(Android 8.0 이상)로 옮겨 설치합니다. 처음이라면 기기 설정에서 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.

### 방법 2. Android Studio에서 직접 빌드

1. Android Studio(최신 안정 버전)에서 `kids-edu-app` 폴더를 엽니다.
2. Gradle 동기화가 끝나면 기기나 에뮬레이터를 연결하고 ▶ Run을 누릅니다.

명령줄로 빌드할 때:

```bash
cd kids-edu-app
./gradlew testDebugUnitTest   # 단위 테스트
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
```

> 음성 안내에는 기기의 한국어 TTS가 필요합니다. 소리가 나오지 않으면 기기 설정 > 텍스트 음성 변환(TTS)에서 Google 음성 엔진의 한국어 데이터를 설치해 주세요.

> Play 스토어 배포용 릴리스 APK/AAB는 서명 키가 필요합니다. Android Studio의 **Build > Generate Signed App Bundle / APK**를 이용하세요. Google Play 가족 정책(아동 대상 앱)도 함께 확인해 주세요.

## 사용 팁 (보호자·교사)

- **앱 고정(화면 고정)**: 기기 설정에서 켜 두면 아이가 다른 앱으로 나가지 않습니다.
- **함께 이야기하기**: 기분 친구 놀이가 끝나면 "나는 언제 그런 기분이 들었어?"라고 물어보세요. 그림 그리기를 마치면 무엇을 그렸는지 이야기를 들어 주세요.
- **영역 고르게**: 보호자 메뉴의 영역별 막대그래프에서 적게 한 영역의 놀이를 함께 해 보세요.

## 프로젝트 구조

```
kids-edu-app/app/src/main/java/com/ssukssuk/playground/
├── MainActivity.kt          # 전체 화면, 뒤로 가기, 앱 생명주기
├── core/                    # 순수 Kotlin: 놀이·영역 정의, 난이도, 설정·기록 저장소
├── content/                 # 순수 Kotlin: 자음·낱말, 감정 상황, 스티커, 노래, 한국어 조사 도우미
├── logic/                   # 순수 Kotlin: 문제 생성기, 짝꿍 카드 규칙, 보호자 확인 문제
├── audio/                   # 순수 Kotlin: 효과음·실로폰 음 합성, WAV 인코더
├── platform/                # Android: TTS(TextToSpeech), SoundPool, SharedPreferences
└── ui/
    ├── AppState.kt          # 화면 전환, 쉬는 시간, 스티커·별 상태
    ├── SsukSsukApp.kt       # 최상위 화면과 놀이 호스트(축하·보상)
    ├── components/          # 쑥쑥이 캐릭터, 하늘 배경, 색종이, 버튼, 도형, 손가락 그리기
    ├── screens/             # 첫 실행, 홈, 스티커 책, 보호자 확인·메뉴, 쉬는 시간
    └── games/               # 놀이 10종
```

`core`, `content`, `logic`, `audio`는 Android에 의존하지 않아 JVM 단위 테스트로 검증합니다(`app/src/test`).
조사 선택(사과**가**/별**이**, 기역**으로**/리을**로**), 고유어 수사(한 개, 두 마리), 문제 생성 규칙, 짝꿍 카드 규칙, 기록 저장, 음 합성 등을 테스트합니다.

## 새 놀이 추가하기

1. `core/Game.kt`의 `Game`에 항목을 추가합니다(제목, 아이콘, 누리과정 영역, 관련 내용).
2. `ui/games/`에 `@Composable fun NewGame(env: GameEnv)`를 만들고 `GameScaffold`로 감쌉니다. 끝나면 `env.complete(맞힌 수, 문제 수)`를 호출합니다.
3. `ui/games/GameEnv.kt`의 `GameContent`에 연결합니다. 홈 화면 타일과 보호자 기록은 자동으로 추가됩니다.
